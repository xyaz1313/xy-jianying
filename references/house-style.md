# Talking-Head Edit Preset

Back to Knowledge Library MOC · used by 2026-11-17 AI Auto-Editing with JianYing · skills: AI Editing Skill Stack

> 小爷自己的**口播剪辑风格**（2026-11-17 小爷在剪映 11.8 里亲手调好、截图给 Agent）。Agent 剪口播时**默认套用这一套**；小爷改了就在这里更新，并在变更记录里加一行。

## 节奏
- 变速：**常规变速 1.10x**，不开声音变调
- 去气口：剪掉开头的空拍（录制按下后、开口前的那段）、句间超过 0.35 秒的停顿（留 0.12 秒呼吸）、结尾的空拍。**由 Agent 根据音频能量 + 逐字时间戳自动完成**，小爷不用手动标

## 画面 → 美颜美体（只给真人出镜的片段，拍屏 / 录屏片段不加）
模式：多人脸模式

## 滤镜（小爷说的"高清增强"）
- 剪映滤镜库 → 收藏 → **「高清增强」**，作为滤镜轨覆盖整条时间线
- 强度：平时 **26–30**；这一次设的是 **34**
- 收藏夹里还有「阳光肤」「高清」两款（这次没用）

## 音频（首版截图，已被下面的决定取代）
- 截图里是 +12.1 dB；Agent 实测原始峰值已经到 −1.4 ~ −2.5 dBFS，+12 dB 会爆音 → 小爷改成 **+6 dB**
- 没开：响度统一、音频降噪、人声美化

## 字幕（逐字稿）
- 小爷的习惯：剪映 **字幕 → 识别字幕**（自动检测语言）生成字幕后再改样式
- 字体：**新青年体**（已收藏）
- 字号 **6**，颜色 **白色**，字间距 0，行间距 0，居中对齐
- 预设样式：第 2 个（白字黑边）
- 描边：**黑色**，不透明度 100%，粗细 **70**
- 位置：X 0，**Y −1577**（画面底部），缩放 100%
- ~~Agent 曾建议用「文稿匹配」~~ → 主人否掉（会多出一条字幕轨、一大坨字）。**现行做法：剪映「一键识别」+ 自定义热词**（如 私域、纯扯、牢饭），识别后统一改样式；听错的个别字在剪映里手动改

## 重点大字（= 封面风格）
- 字体：**仓耳榜黑**（会员，已收藏）；收藏夹里其他字体：与墨体、BREXTER
- 颜色：**白字 + 粗黑描边**，重点词用**玫红 `#FF287F`**（剪映"我的颜色"里第 3 行第 3 个）
- 位置：**偏上，避开人脸**，像标题一样放在画面上方
- 入场：打字机或放大，都可以
- 参考：小爷的封面"**CLAUDE**（玫红）/ **不能用了又如何**（白）"，粗黑描边

### ⭐ 大字摆放铁律（小爷 2026-11-18，长期有效）
- **画面里有人时，大字绝不能挡人脸** → 放**左上角或右上角**（离脸远的那一侧）
- ~~画面里没人时（拍屏、录屏、素材画面）→ 可以放中间或上方~~ → 2026-11-18 改为下一条
- **大字永远不放正中间**（小爷 2026-11-18）：只放左上或右上，把画面中间留出来。有人 → 放离脸远的一侧；没人（拍屏、录屏）→ 放**更空的一侧**（大片墙、暗处），画面导演在真实画面上比较两边有多「乱」再决定；字号同样 13，不再用居中 14
- **大小和排版（小爷 2026-11-18 亲手调的参考，长期有效）**：上下两行**永远贴在一起**（中间不留缝），两行**都贴着外侧边对齐**——放右边就右对齐、放左边就左对齐、没人时居中；第一行离画面顶边约 2%，离侧边约 1.6%（4K 画面约 60 像素）
  - 小爷的参考值（「彩排五号」0:09「AI创业兄弟 / 千万别上当」）：上行 字号 8 · 缩放 160% · X 2186 · Y 1761；下行 字号 8 · 缩放 157% · X 2331 · Y 1125
  - 字号 8 × 缩放 160% = 字号 12.8 的效果 → 默认 **字号 13**（缩放保持 100%）；拍屏画面（没人）用 **字号 14**
  - 只有真的会挡到脸时才缩小，一次小 1 号，最小 9；先换到另一侧、再往下挪，最后才缩小
- 字体、颜色、描边按上面的设置，小爷确认"都没问题"
- **字体永远是仓耳榜黑**（大粗那款），不能换（小爷 2026-11-18 强调）
- 重点词颜色**不限于玫红**：可以用绿、黄等穿插，由「视觉导演」按情绪和节奏安排，保证酷炫但统一
- **平台合规（小爷 2026-11-18）**：画面上的字（大字、小字、标题）**不能有导流词**——「免费送 / 送你 / 送给你 / 领取 / 私信 / 加微信 / 扫码 / 进群 / 评论区扣1」等，平台会判导流。例：「横版Skill / 免费送你」→ 改成「自动剪辑 / 横版Skill」。视觉导演遇到这些词会直接停下（`scripts/compliance.py`）；口播里说到的（字幕会出现）列出来给小爷决定
- **导流钩子：嘴上可以说，画面不能出**（小爷 2026-11-18）：口播里「…送给你们 / 找我拿」是引私域的钩子，**声音保留**；但这句的**字幕删掉**、大字不写。剪辑时 `live_run` 第 5 步会按逐字稿找到这类句子，自动删掉对应字幕
- **工程标签不进成片（小爷 2026-11-18）**：「STEP 3 · 美颜」「加大字」「完成」这类说明只能在剪辑过程中（光效层）出现，**成片 / 交给小爷的草稿里不能有**；加速标「»» 加速 ×N」小爷要保留
- **大字必须有入场动效**（小爷 2026-11-18）。视觉导演默认按情绪配：钱 / 诱饵（黄）→ **打字机I**（像聊天消息一样打出来）；骗局 / 警告（玫红）→ **放大**（砸出来）；我方观点（绿）→ **向上弹入**。剪映里可选的入场还有：渐显、跳跃登场、打字光标、粒子划入、逐字显现、复古打字机、光线划过、金粉飘入、滚入、打字机II
- 每条视频剪之前，先由「画面导演」逐个检查大字出现时的画面（有没有人、脸在哪），给出每个大字的位置方案，**小爷确认后才动手**

## 音频
- 音量：**+6 dB**（小爷 2026-11-17 确认，替代原来的 +12.1 dB）
- 中长视频：**不加 BGM，不加音效**（短视频才加）

## 调色
- 只用「高清增强」滤镜，**不额外调色**（小爷的拍摄环境一直这样）

## 导出
- **AI 不导出**（小爷 2026-11-18）：剪完留在剪映**草稿箱**，小爷审核、微调后自己导出
- 小爷自己导出时用：**4K、30 fps、原画质**

## BGM（小爷 2026-11-18）
- **曲子**：「22 22」— DiCrow（5:00），在剪映 → 音频 → 我的 → **收藏**里（小爷已下载；缓存文件 `Cache/music/7bf74ea71d1ea36ce76eb9715c747260.mp3`）
- **音量 −6.3 dB**（小爷 2026-11-18：−5.3 dB 还是会盖住人声）；从头铺到尾
- **不加淡入淡出**：片子结束就结束，多出来的一两秒只会拉低完播率
- **什么时候加**：有大段加速、空白、没人说话的地方（过程演示类视频一定加）；纯口播看情况，先问小爷

## 封面（小爷 2026-11-18）
- 风格：抽一帧 + 仓耳榜黑两行（上玫红 #FF287F、下白、粗黑描边、两行贴紧、**居中**）；横版 16:9 字在中间 4:3 区域内；竖版 3:4 两帧上下拼、字压在接缝上；先做横版 → 导出视频 → 再做竖版
- **表情：眼睛要睁开、有神**，眼睛半闭（「含着」）、表情奇怪的帧不用（小爷 2026-11-18 否掉了竖版下面那张）
- **排版（量自小爷的参考封面）**：两行**一样宽**，描边贴着描边几乎连在一起，字放到最大——横版每行约占画面宽 58%（中间 4:3 区域的 77%），整块中心在 73% 高；竖版每行约占 86% 宽，描边快碰到左右边，压在接缝上
- **挑帧铁律：不露牙齿**（作者偏好）；要最帅的一帧——小爷示范：手托麦克风挡住嘴、眼睛看镜头的那种（「过程演示」那期的 #4）
- 工具：`scripts/cover_frames.py` 先自动打分 + 过滤露牙的帧（只是初筛，最后小爷挑），`scripts/cover_render.py` 出 16:9 + 3:4

- **导出与发布文件夹（小爷 2026-11-18）**：平时只留草稿；小爷说导出才导出（4K 30fps MP4）。每期一个文件夹 `<导出根目录>\YYYY-MM-DD 标题\`（config.json → export_root，小爷用 `D:\视频成品`），里面：成片 mp4 + `封面-横版16x9.png` + `封面-竖版3x4.png`，小爷从这里发布。剪映会在「导出至」里再建一层以标题命名的文件夹 → 「导出至」选导出根目录、标题写「YYYY-MM-DD 标题」，导出后把两张封面放进剪映建的那个文件夹。剪映导出完成窗口的「发布」按钮绝不点
