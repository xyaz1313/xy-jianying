# assets

Nothing is bundled here on purpose.

- **Fonts** (仓耳榜黑, 新青年体) are 剪映 member cloud fonts; they are read at runtime from
  `%LOCALAPPDATA%\JianyingPro\User Data\Cache\effect\**\<name>.ttf` (see `scripts/director.py`) and must not be
  redistributed.
- **Beauty preset** 「我的预设1」 lives inside 剪映 (美颜美体 → 美颜预设); values are in
  `references/house-style.md` if it has to be recreated.
